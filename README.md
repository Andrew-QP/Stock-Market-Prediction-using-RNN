# Stock-Market-Prediction-using-RNN

This research analyzed the accuracy and performance of three Recurrent Neural Network (RNN) architectures: Simple RNN, Long Short-Term Memory (LSTM), and Gated Recurrent Unit (GRU). It used historical Apple stock data (1980-2020) to predict the next day's closing price. Recognizing the volatility of financial markets, 17 engineered features were derived beyond the standard OHLCV data to enhance pattern capture compared to using raw price data alone. The models were trained and evaluated using Mean Absolute Error (MAE), Mean Squared Error (MSE), Root Mean Squared Error (RMSE), R-Squared (R²), and threshold accuracy metrics on a held-out test set after utilizing a separate validation set for model selection. The comparative analysis found that the GRU model delivered the strongest predictive performance, achieving the highest R² (0.983) and the lowest RMSE ($7.55). The results also indicated that both gated architectures (LSTM and GRU) significantly outperformed the Simple RNN, underscoring the effectiveness of memory mechanisms for modeling this financial time series.
