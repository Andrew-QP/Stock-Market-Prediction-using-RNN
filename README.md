# Stock-Market-Prediction-using-RNN

In this research, the accuracy and performance differences from three Recurrent Neural Networks (RNN) will be analysed using historical stock data from Apple to predict the closing price of the next day. Due to the volatility and unpredictable nature of the stock market, additional features will be created from the original 5 features to enhance capturing patterns from previous days. The three RNNs include, a basic RNN, Long Short-Term Memory (LSTM), and Gated Recurrent Unit (GRU).
